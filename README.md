# 值班提醒（iPhone App）

一个专门给自己用的排班 / 值班提醒 App：

- 🌅 每天 **7:30** 推送「今天：白班」
- 🌙 每天 **20:30** 推送「明天：夜班」
- 📅 日历模式查看整月排班，点某一天可以手动修改，并显示本月统计
- 🔄 下拉刷新，从值班系统自动同步最新排班
- 👤 多人排班表里按「设置 › 我的名字」自动找出自己的那一行或那一列
- 🔐 支持用户名密码（存在系统钥匙串），或在 App 内网页登录
- 🌗 深色模式（跟随系统，也可手动切换）

提醒时间、名字、班次颜色都可以在「设置」里改。

## 不需要服务器，怎么做到自动更新

全部在你自己的 iPhone 上完成：

1. **在 App 里登录值班网站**：「设置 › ① 登录值班网站」，像平时一样登录，打开能看到排班表的页面，点底部「设为同步地址」。
2. **自动刷新**：之后每次打开 App（超过 15 分钟未同步）、下拉刷新、以及 iPhone 在后台空闲时（系统决定，大约每隔一两个小时），
   App 会用一个看不见的内置浏览器、沿用你的登录状态打开那个页面，读出你的排班。
3. **有更新就提醒**：和上次比较，今天及以后的排班有变化就立刻推送「📢 排班有更新：10月12日 周一：白班 → 夜班」。
   登录过期时推送「⚠️ 值班网站登录已过期」，重新登录一次即可。
4. **每天定时提醒**：iPhone 允许 App 提前登记本地通知，App 会把接下来约 30 天的「今天：白班」「明天：夜班」都登记给系统，
   到点由系统弹出，就算 App 没在运行、没联网也会提醒。排班里写了具体工作内容（如「白班 门诊二楼」）也会显示在通知里。

> 后台刷新的时机由 iOS 决定，手机长期不打开这个 App 时，系统会减少后台刷新次数。偶尔打开一下就好。
> 不要在「设置 › 通用 › 后台 App 刷新」里关掉它。

## 推送到微信（可选）

「设置 › 微信推送」里打开，填入 [PushPlus](https://www.pushplus.plus) 的 token（微信扫码登录官网，在「一对一推送」里复制）。

- 排班变动、登录过期：同步时立即发到微信
- 每天的提醒要准点发到微信，用 iPhone 自带的「快捷指令」自动化（App 自己不能准点在后台运行）：
  1. 打开「快捷指令」App › 底部「自动化」› 右上角「+」› 选「特定时间」
  2. 时间 7:30、重复「每天」，选「立即运行」（不要选「运行前询问」）› 下一步
  3. 「新建空白自动化」› 添加操作 › 搜索「值班提醒」› 选「发送值班提醒到微信」，「哪天」选「今天」
  4. 再建一个 20:30 的，「哪天」选「明天」
- 建议再建一个 **7:00** 的自动化，动作选「**同步排班**」，保证 7:30 的提醒和微信用的是最新排班
- 没设自动化时，微信这份会在 App 有机会运行时补发（打开 App 或系统后台刷新），可能比准点晚
- 只发送自己的分工（如「今天：组D」），不发送网页上的其它内容

## 多周排班（自动识别数据接口）

排班网页大多是先向服务器的数据接口取排班、再显示出来。后台同步时 App 会记下网页取了哪些数据（只在手机内存里），
自动认出其中的排班数据，再用同一个登录状态、同样的请求，把日期往后推 1～3 周取后面几周的排班。
认不出接口时照旧读网页上显示的内容。「设置 › 诊断」里可以看到是否已识别、排班最远到哪天。

## 首页、组别说明与搜索成员

- 首页顶部显示日期，今天 / 明天的卡片下面显示这个组的工作内容（同步时从网页读取，也可以在「设置 › 显示 › 各组工作内容」里自己填）
- 首页右上角放大镜可以搜索成员，列出他的全部排班。同步时 App 会打开网站的「值班查看」页面读取全员排班，只保存在手机上
- 排班变动：之前已经取到过的日子真的改了才提醒；新一周第一次取到不算变动。微信那份可以在「设置 › 微信推送」里单独关掉

## 签名到期与诊断

- 用免费 Apple ID 签名的 App 7 天到期。App 会在到期前 1 天提醒你「打开 SideStore 点 Refresh All」，「今天」页也会显示提示。
- 「设置 › 诊断」一页显示同步、登录、提醒、小组件、微信推送的状态，出问题时截这一页即可。

## 其它导入方式

| 方式 | 说明 |
| --- | --- |
| **抓取本页** | 在内置网页里打开排班页面，点「抓取本页」，预览后导入（一次性）。 |
| **文件网址** | 如果值班系统能导出 CSV / 日历订阅（ICS、webcal://）/ JSON 地址，填进去并关掉「用内置浏览器同步」。 |
| **粘贴 / 文件导入** | 从 Excel / WPS / 微信里复制排班表直接粘贴，或选择 CSV / ICS / TXT 文件。 |
| **手动** | 在「日历」里点某一天选择班次。 |

能识别的排班表格式（`ShiftCore` 里有对应的单元测试）：

```
# 每人一行、表头是日期（最常见的月度排班表，表头只写 1 2 3… 也可以）
姓名    10/9   10/10   10/11
张三    白     夜      休
张伟    夜     休      白

# 每人一列
日期,张三,张伟
10/9,白,夜

# 列表
2026-10-09 白班
10月10日 周六 夜班
10/11 休 10/12 白 10/13 夜
```

班次文字会自动归类：包含「白/早/D」→ 白班，「夜/晚/N」→ 夜班，「休/假/off」→ 休息……
可以在「设置 › 班次类型与颜色」里改关键字、颜色和图标。

## 安装到 iPhone

### 有 Mac（推荐）

1. 安装 Xcode 和 XcodeGen：`brew install xcodegen`
2. 在项目目录执行 `xcodegen`，打开生成的 `ShiftReminder.xcodeproj`
3. 在 *Signing & Capabilities* 里选择你的 Apple ID（免费账号也行），必要时把 Bundle ID 改成独一无二的
4. 手机用数据线连上 Mac，选择你的 iPhone，点运行 ▶︎
5. 第一次需要在 iPhone「设置 › 通用 › VPN 与设备管理」里信任开发者

> 免费 Apple ID 签名的 App 7 天后需要重新安装一次；付费开发者账号（99 美元/年）为 1 年，也可以用 TestFlight。

### 下载地址

最新安装包（每次更新代码后自动生成，不用登录 GitHub）：

**https://github.com/wuyong9494-lab/kriswu/releases/latest/download/ShiftReminder.ipa**

在 iPhone 的 Safari 里打开即可下载到「文件」，再用 SideStore 的「+」选择它安装。

### 没有 Mac

每次推送代码，GitHub Actions 会在 macOS 上自动测试并编译，产物里有 **未签名的 `ShiftReminder.ipa`**
（仓库 › Actions › 最新一次运行 › Artifacts）。可以用 Sideloadly / AltStore 等工具配合自己的 Apple ID 签名安装。

## 目录结构

```
Sources/ShiftCore/   与平台无关的核心逻辑（可在任何装了 Swift 的电脑上 swift test）
  ScheduleParser       解析 ICS / JSON / CSV / 表格 / 文字，找出自己的排班
  DateTokenParser      解析各种日期写法
  ShiftType            班次类型、关键字匹配
  NotificationPlanner  计算接下来要推送的提醒
  HTMLText             网页表格转文字
App/                 SwiftUI 界面、通知、同步、钥匙串
Tests/ShiftCoreTests 单元测试
project.yml          XcodeGen 工程配置
```
