# 照片编号与名称片段核对

用户明确只能提供照片，无法走 Excel 导入流程。本轮继续处理拍照计划中的编号误识，不宣称照片 OCR 可以保证所有输入 100% 正确。原始业务照片仍保留在私有工作区，不上传公共仓库或 CI。

## 待验证实现

只有照片中明确存在独立的卫星 ID 和卫星名称列，且行的完整开始时间、ASCII 圈号、站名、原格和几何信息齐备时，才提取名称末尾真实读出的混合数字字母片段，例如虚构名称「演示07D星」的 `07D`。名称必须只包含一个“星”且以其结尾；片段不允许由 O/0 替换、编号词库或模糊匹配产生。

当前 ID 已包含该片段时保持原值。否则裁切该行原始编号格，以英文 accurate、关闭语言纠错与 customWords 复识，每页最多 64 次。必须实际读出完整 ASCII 编号，其长度与原 ID 相同，名称片段在新读数中唯一出现，片段之外所有字符与原 ID 完全一致，才采用该完整读数。数字前缀、未被名称覆盖的后缀都不能删改。仅规范比较中的空白和大小写，不设置 O/0、1/L、5/6 字符替换规则。

名称也是 OCR 读数，因此核对相符不是独立真值证明。补读保留原有全部疑项，另记原 ID；照片编号人工确认要求仍生效，test 不参与，其他行字段不变。单列编号表、名称残缺、重复片段、非 ASCII 候选、前后缀变化均保持原值。

## 验证要求

- 新增 10 项核心回归，覆盖真实片段条件、完整原格证据、前后缀与数字前缀、合法字母 O、布局与原格一致性、test、元数据与人工确认。
- 新增 1 项实际 Vision 原生测试，包含清晰编号像素、相邻列干扰、不同前后缀、test、原值已相符和不可用名称。
- 四张既有公开合成全图、冻结真值与全部既有原生断言保持。与已验证的 Build 521 的 188 行最终结果逐字段比较，分别统计错→对、对→错、仍错和无法独立对应的变化，不以测试通过或提示数量作为精度证明。
- 改动在独立分支验证，结果尚未取得，不合入已验证主分支，不发布 TestFlight。若没有收益或出现已正确编号被改错，应收紧或撤回方案；不得按真值硬编码修复个别样例。
