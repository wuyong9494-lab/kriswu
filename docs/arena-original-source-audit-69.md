## 已产生的真实离线成果

### 配置关系

`audit/adapted/enabled_heroes.json` 保留全部 118 条英雄与默认 skin/skin_conf、
普通攻击、大招、动作、脸部表情的跨表关系。243 个技能、1,451 个动作记录、
534 个被引用的脸部记录已保留。原始形态、分号动作表达式和 `:mesh+mesh`
选择器保持原值，没有默默丢弃或按猜测执行。

`audit/adapted/enabled_locations_maps.json` 保留 468 个地点、370 个完整布局、
35 个主题、49 个模式引用及 75 种地形。未知符号和元数据解析问题单独保留。
不能将原地图行直接交给现有 `ArenaMap`：字符 `C/a/b/o` 等已有冲突，
会误认宝箱/出生点，`M/X/F/W` 等墙、水、草定义也不会自动成为对应地形。

### 贴图、模型、动作和表情

106 个显式默认 SCTX 已全部转换成 PNG，关联 109 条 Hero 配置；源 mip
尺寸、长度和哈希检查以及 PNG 像素 round-trip 全通过。其余 9 条配置的
diffuse 字段没有明确值，未造图或将其算作丢失文件；默认模型批量转换另从
这些模型内部的真实材质纹理引用解析缺省贴图，保留每个材质 slot 的来源。

Colt 的正确默认链是 `Gunslinger -> GunSlingerDefault -> colt_redux_geo.glb`
与 `colt_redux_tex.sctx`，待机仍是 `colt_idle.glb`。不能把旧 `colt_geo.glb`
误标为本包默认外观。实际转换展开 FLA2、压缩顶点/法线/权重、父子层级、
inverse bind 和 RLE 动画，产出标准 JSON+BIN GLB。Colt 与 Shelly 的标准
身体/骨架/待机样本通过官方 glTF validator 和项目已有 glTF 子集合同检查。
有原层级相关警告，未把这些离线检查当成 iOS 运行验收。

1. 恢复完整私有转换包，校验期望 IPA 哈希；保留逐模型、逐纹理、逐音频状态。
2. 对 SC 主界面输出验证动态文字、mask、布局、动画与状态选择；背景可见不等于大厅可操作。

   模型样本不能代替所有英雄技能、碰撞、伤害、召唤、形态、存档和联机设计。
4. 明确原地图的符号、出生/目标、可破坏墙、水域、跳板等语义再实现适配。

6. 只有真实 App 接入与必要构建检查完成，且素材的适用使用范围明确后，
   才处理下一次发布。不要复用 475 的测试证据证明本次新资源已通过。
