# 计划识别退步排查 · 2026-11-05

用户反馈 App 识别计划比之前更不准。结果页截图不能代替同批原始表格的真值；此前四张原图属于另一批计划，仅作私有版式核对，没有进入公开仓库或 CI。

## 本轮具体修复

`PassPlan.combine` 原先先按整页得分选底稿，再按每行问题数量选择整行替换。较短的一轮只要补回一个站名或圈号，就可能同时覆盖底稿已有的完整时间、卫星名称和数传参数。两轮分别缺失不同字段但问题数相同时，也无法互补。

改为在同页、唯一几何对应的行内逐字段补全：已有完整值保持，空值或明确格式错误才可使用另一轮原读数。完整但不同的值仍显示冲突；不猜改 O/0、C/0、数字前缀或卫星后缀。非空卫星 ID 不同的两行不混合字段；没有双侧 ID 时，名称冲突也不补合。补出的起止时间不得形成结束早于开始的新区间。

保留底稿裁条位置、未知列、已有核对提示、左侧应急证据和所有 test 排除出口。被补字段的原始单元格同步更新，避免卡片与导出表不一致。照片编号仍须逐项确认。

## 验证范围

新增六项核心回归：站名补全不带坏其他字段、互补读数、重排列与导出一致性、不同编号隔离、时间区间约束、应急与 test 保留。完整核心套件和 `SiteTests/PlanReaderTests`（包含既有四张公开虚构全图）尚待本轮 CI 执行。

本轮修复的是合并丢失正确字段的确定性问题，不把测试方法通过、警告减少或可发送错误数为零等同于 OCR 精度合格。真实照片当前尚未在 Apple Vision 环境逐字验收；与截图对应的这批原始计划也尚未取得。
