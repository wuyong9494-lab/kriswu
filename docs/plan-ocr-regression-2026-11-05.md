## 本轮具体修复

`PassPlan.combine` 原先先按整页得分选底稿，再按每行问题数量选择整行替换。较短的一轮只要补回一个站名或圈号，就可能同时覆盖底稿已有的完整时间、卫星名称和数传参数。两轮分别缺失不同字段但问题数相同时，也无法互补。

改为在同页、唯一几何对应且身份相容的行内逐字段补全：已有完整值保持，空值或明确格式错误才可使用另一轮原读数。完整但不同的值仍显示冲突；不猜改 O/0、C/0、数字前缀或卫星后缀。非空卫星 ID 不同的两行不混合字段；没有双侧 ID 时，名称冲突也不补合。身份冲突时沿用修改前的整条候选择优，问题数量相同则保留底稿，并保留所有冲突提示。补出的起止时间不得形成结束早于开始的新区间。

保留底稿裁条位置、未知列、已有核对提示、左侧应急证据和所有 test 排除出口。被补字段的原始单元格同步更新，避免卡片与导出表不一致。照片编号仍须逐项确认。
