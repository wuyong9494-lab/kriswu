# 地图精美度与多样性：三张样板的设计合同

第三轮研究规划，未制作地图文件、修改地图池或导入环境素材。参考和源码身份见[证据台账](arena-quality-evidence-2026-10-30.md)。坐标只是供未来灰盒制作的设计说明，未进行可玩性验收。

## 1. 原版观察证据 → 当前差距

V02 00:42.09 的足球画面可辨地面、较亮草丛、木箱/桶/矮栅栏以及灰蓝障碍；V01 01:19.94 则是浅色赛场及另一套障碍造型。两者说明主题可以大幅变化，但道路、角色和障碍关系仍要清楚。它们不证明这些障碍的全部碰撞/破坏规则。

官方 Map Maker 将模式、主题和放置物分别选择；2023 的官方地图调整记录讨论布局区分与接敌节奏。这里据此提出分离评审的办法：**玩法灰盒通过后，替换视觉不能改变碰撞**；只换颜色计为主题变体，不计为新玩法地图。

项目已有14张基础图、7张扩展图，团队图/混战图和benchmark选图路径不同。只看到某一张测试图不能代表全部正常对局。现有地形类型为 floor/wall/bush/goal，另有动态箱体、塔和模式物件；没有现成水格/可破坏墙合同。因此首批样板只用已支持规则，不把美术画成水、桥或可炸墙来暗示未实现功能。

## 2. 模式 × 布局 × 主题矩阵

| 样板 | 模式 | 布局决策 | 首主题 | 可换主题及边界 | 首轮验证角色 |
|---|---|---|---|---|---|
| A 双闸交汇 | 占点 zone | 中路短、侧路长；两个侧入口可夹击，中央不能被一面墙永久保护 | 蓝月港：青蓝地面、暖金属掩体 | 琥珀矿场仅为同布局视觉A/B，不增地图数 | 游侠/骨盾卫/法师+书灵作组合对照 |
| B 斜径花园 | 足球 ball | 错位掩体产生斜线传球与侧路推进；守门前留恢复空间 | 温室遗迹：深绿地面、浅草、暖石/木 | 蓝月港可作为后续主题变体，球门/球轨迹规则不变 | 骑士/飞镖手/幽影，另测全远程 |
| C 分路矿库 | 宝箱攻防 heist | 中路较快但暴露；两侧绕行威胁后方，逼防守者在守家/推线之间选择 | 琥珀矿场：低饱和沙岩、深色机器与暖亮边 | 温室变体必须保留保险箱/出生区语义 | 游侠/法师/骨灵，另测三近战 |

首批只排 A→B→C 三张。不要同时生产3模式×3布局×3主题的27张。A先证明风格与性能；B验证近战/球体可读性；C验证路线分工与持续目标压力。

## 3. 坐标约定和制作顺序

坐标为整数格索引，左下角(0,0)，格中心为(x+0.5,y+0.5)，宽W高H。矩形端点包含在内；R(x,y)=(W−1−x,H−1−y)为180°旋转，对下面列出的半图地形取并集。实际代码行数组的上下方向由接入者显式转换，不能直接照抄造成队伍颠倒。

除明确边界、墙、草、目标外为可通行地面。首版不随机生成地形或箱体，保持重复实验一致。先记录网格与碰撞，再放美术；首版不安排只能靠某角色技能通过的孤岛。路径宽度按碰撞体实测，至少2格通道为灰盒设计起点。

### A 双闸交汇：21×29，占点

| 元素 | 首版位置/参数 |
|---|---|
| 边界 | x=0/20 或 y=0/28 不可走；场外装饰在边界外 |
| 出生 | 下队(5,3)、(10,3)、(15,3)，上队取R；实际站位为格中心 |
| 目标 | 中心(10.5,14.5)，首版沿用当前 zoneRadius，不自行扩大；美术地面圈读取实际半径 |
| 半图墙 | x3–5,y8；x8–9,y10；x13–16,y8；x3–4,y12；x15–16,y12；以及全部R |
| 半图草 | x1–2,y9–11；x6–7,y11–12；x17–18,y9–11；以及全部R；不覆盖墙 |
| 主要开口 | 中线x10贯通；左侧x5–7与右侧x13–14绕过墙片；外围x1–2/18–19供长绕行 |
| 视觉锚点 | 目标区下沉色块、两侧港口闸门轮廓放场外；不做可互动开关假象 |

设计假设：远程控制中线，盾卫利用短墙接近，投掷压墙后，但对方至少能从另一侧逼出。中央占点不能有一个墙后位置同时覆盖两出生出口。

风险：中线通视使游侠统治；近战侧路太长，尚未到点已失去目标；长草连接触发现有连通草视野规则。测试中心首次接敌、侧路耗时、中线命中率、每条入口实际使用率。若中线压制过强，优先调整墙片/入口而非全体削射程。

### B 斜径花园：15×25，足球

| 元素 | 首版位置/参数 |
|---|---|
| 边界/球门 | x=0/14边界；y=0/24，x5–9为goal，其余边界为wall；保持当前人/球对goal差异 |
| 出生 | 下队(4,3)、(7,3)、(10,3)，上队R；球在(7.5,12.5) |
| 半图墙 | x2–4,y7；x9–11,y9；x5–6,y10；以及全部R |
| 半图草 | x1–2,y9–11；x10–12,y5–6；x4–5,y5；以及全部R，不覆盖墙或门前缓冲区 |
| 门前缓冲 | 下方x4–10,y1–4不添加墙/草；上方R；避免重生即被贴墙堵死 |
| 关键空隙 | 中央留可过人的斜线交换空间；左右至少各一条非技能路线；用实际球半径验证传球通道 |
| 视觉锚点 | 门框、球、进攻方向，花盆/树冠放外围；不让装饰线看起来像墙 |

设计假设：直冲受错位掩体约束，传球和改线比纯直线射击有价值。近战能借短掩体接近，回旋角色能用站位改变返程，远程仍有清晰但不连续的射击窗口。

风险：幽影跨墙持球成为必选；墙缝球能过人不能过但画面未提示；门前装饰遮住球。测试每道空隙的球/人通过、持球普攻/大招、射门和重生，分开统计单人带球与双人传球，不仅比较进球数。

### C 分路矿库：15×25，宝箱攻防

| 元素 | 首版位置/参数 |
|---|---|
| 边界 | x=0/14或y=0/24不可走 |
| 出生/宝箱 | 下队(3,4)、(7,4)、(11,4)，上队R；下宝箱占x6–8,y2–3，上宝箱R；按现有ChestSpot定义接入 |
| 半图墙 | x4–5,y7；x9–10,y7；x6–8,y10；以及全部R |
| 半图草 | x1–2,y8–10；x12–13,y8–10；以及全部R |
| 关键路线 | 中路绕中央墙片，左右可从x1–3或11–13远绕；宝箱侧面至少两条地面路径可接近 |
| 视觉锚点 | 宝箱本体比周围矿具亮；机械管道均在场外，不能画假高地/可站桥 |

设计假设：射手逼退防守，投掷者从墙后施压，召唤者在推线与守家间取舍。侧路不是额外一条完全等价的道路，而是用更长移动换攻击角度。

风险：投掷者安全打箱、骨塔持续刷目标、三人偷家无法反制。测试从所有可站格攻击宝箱的暴露程度、回防时间、召唤物放置封路及塔被摧毁后的空窗；不能靠对称坐标宣布平衡。

## 4. 环境美术制作规范

| 部件 | 首样板制作要求 | 质量检查 |
|---|---|---|
| 地面 | 大块低频色变化，路径亮度稳定；不在关键战区铺强对比裂纹/花纹 | 原尺寸能找到弹芯；去装饰后路线保持一致 |
| 墙 | 顶面、立面、边缘有三个可区分层次；高度/倒角在三主题保持统一逻辑 | 阴影不虚增碰撞范围；脚底遮挡不能掩盖接触边界 |
| 草 | 成片轮廓清楚，边界对应格；内部只少量叶片变化 | 100次边缘进出；草动画不能被误认成敌人显形；不改现有视野规则 |
| 地图边缘 | 场内边界与场外装饰分区；用整体形状说明不可进入 | 无“看似能绕”的假通道，四角相机不露空白 |
| 装饰 | 最大可见高度和体积先按角色遮挡检查；优先布置于不可走外围 | 关键交战区不被树冠、旗帜、前景墙覆盖 |
| 光照 | 一个主方向+柔和环境层，战区明暗变化克制 | 暗图敌我标记、浅图技能边仍可读；切主题不改变危险语义 |
| 配色 | 蓝月港青灰/暖铜；温室深绿/浅草/暖木；矿场赭灰/暗金属/少量亮矿晶 | 三主题对同技能做色弱/灰阶对照；绿治疗不融进草 |
| 比例 | 一格为玩法尺度；墙高、草高、箱体和角色足点统一标尺 | 场外装饰可夸张，场内视觉不能暗示错误遮挡/通行 |

初始模块清单：地面直块/边块/转角3件、墙直段/端盖/内外角4件、草整块/边/角3件、模式目标1组、外围装饰4–6件。先共用一套材质规范，不为每个小块开独立材质。轮廓、UV、贴图源与碰撞标尺分别交付。

## 5. 所需资源与性能包络

需要关卡设计、环境美术、技术美术/SceneKit接入、真机测试；不需要在首批增加水面、动态破坏或昼夜系统。现有shader与资产可用于验证风格方向，是否保留需通过实际截图。

建议首地图2张1024环境图集、1张512装饰/草图集、不透明为主。RGBA8含mip估计2×5.33+1.33≈12MiB，不含引擎副本、渲染目标和CPU图像；最终压缩驻留以设备为准。2张图集不是固定行业标准，只是控制材质分散的首版包络。

按静态地形/角色/动态物/技能分别测GPU与CPU。环境装饰打开相对玩法灰盒的增量目标：GPU P95≤2ms、CPU P95≤0.5ms；若失败查实例提交、透明覆盖与阴影，不优先削减关键掩体或改变布局。几何/材质共享是否真正合批须用GPU帧确认，不能从源码字典缓存直接推断。

## 6. 验收方法

| 阶段 | 检查与记录 | 退出/返工条件 |
|---|---|---|
| 静态设计复核 | 网格边界、对称映射、出生与目标不重叠；圆形碰撞体可走路径；最窄通道 | 任一出生无普通地面路径到目标即返工；本轮未运行拟议地图 |
| 灰盒路线 | 3类移速、左右/上下换边，记到目标/首次射线/侧路/回防秒数 | 对称同角色路线理论等价；实际差异>5%先查相机/碰撞/输入，不直接调攻击 |
| 角色覆盖 | 远程、近战、投掷、辅助/召唤至少各一人 | 各类至少有可解释机会和反制；“受限”可接受，“无可行动路径”不可接受 |
| 多人对局 | 固定阵容换边、再跨阵容；路线上热区、首次击杀、目标时间、复活后再接敌时间 | 一条路线长期无人选、单一点位支配全部路线需改布局；少量对局不宣称平衡 |
| 美术替换 | 灰盒与成品碰撞哈希/网格一致；三主题同机镜头对照 | 视觉引起的误判与原规则问题分开记；禁止用美术偷偷修碰撞 |
| 压力/长测 | 6人技能集中于目标，草边/墙角同时移动；30分钟热稳定记录 | 可读性和性能两者都过；截图漂亮但走动闪烁则不通过 |

首轮每图建议12局探索（同阵容双方换边×三种代表阵容×两次），用于发现问题；后续增加到每图至少60局多水平人工测试并报告分层数据。机器人可查可达性和压力，不能代替有意识绕后与队伍配合。

## 7. 未知问题与准确续接

拟议坐标尚未进入引擎，不能宣称可达性/公平性已验证。原版同版本地图尺寸、破坏规则、视野和镜头精确参数仍未知。先批准A图灰盒后测所有路径和模式目标，再决定是否艺术化；A不通过不启动B/C成品。原地图与地图ID保留作对照，未来新增版本须独立ID及网络版本协商，不能覆盖旧回放含义。
