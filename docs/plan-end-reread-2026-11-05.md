# 结束时间原格复识验证

用户补充了两张原始计划照片。私有逐项核对发现，原图与结果页中一条同卫星、同圈号、同开始时间的记录存在结束时间差异；两页还包含不同日期的计划，不能仅凭名称或时分秒直接配对。原始照片与业务字段没有进入本仓库或 CI。

## 实现范围

原来的合并只会修复空值或格式错误；当两轮得到两个格式都合法的结束时间时，首选整页的时间会一直保留。小图会去重为两种实际识别设置，不能假设它们都有三轮可投票。

新增有条件的原格复识：只有至少两轮按几何双向唯一对应，且完整开始日期时间、卫星编号（或没有编号列时的名称）、圈号、站名都相同，才收集有效但不同的结束候选。只裁该行结束时间格，使用英文 accurate、关闭词语纠错，不读相邻行，不用时长或邻行推算。每页最多 64 个局部请求。

原格必须读出含秒的完整日期时间，并与至少两个不同有效候选中的一个完全相符，才采用那个已有候选。漏秒、只有时分秒、非法日期、结束早于开始、第三个新答案都不能覆盖原值。已有疑项与应急证据保留，test 记录不参与；字段及原始导出单元格同步更新。

这只是候选选择的改进，多路 Vision 仍可能共同读错；人工核对要求没有解除。卫星编号不做任何字符替换或前缀清洗。

## 验证计划

- 新增 8 项核心回归，覆盖重排列、不同日期/身份、双向歧义、局部候选核对、漏秒、跨午夜、元数据与 test 保留。
- 新增 1 项真实调用 Vision 的原生测试：程序绘制虚构完整时间及相邻列干扰值，验证成功修复、拒绝第三个答案、test 与未补读行不变。
- 保留既有四张公开虚构全图、冻结真值和全部原生断言，与 Build 518 的逐行字段结果比较；尚未完成本轮 CI，不能据实现或用例数量宣称准确率提升。
- 改动先放在独立验证分支，未发布 TestFlight，也未覆盖已验证的主修复分支。
