# 叠叠消：星域关卡与牌面升级

用户反馈图片不好看、玩法简单、容易过关。以已验证 Build 526 的修复分支为基线，保留值班、计划原图发送及其他游戏现有成果。

## 这次改动

- 将系统 Emoji 更换为 12 种原生矢量太空插画，统一轮廓、配色和高光；使用陶瓷质感牌面、静态星幕、独立游戏首页、计分栏与结算。图案不是外部游戏素材，也不依赖网络下载。
- 新增固定种子的 12 关星域航程，逐关解锁；保留最好星级和分数。通关一星，无道具两星，无道具且达到本档连消目标三星。
- 新规则轻松 / 进阶 / 大师分别使用 6 / 10 / 12 种牌、4 / 6 / 8 层主体和最多 60 / 120 / 168 张。生成器在各层均衡减牌，避免旧的张数限制优先削掉顶层，使叠层退化。底部储备堆继续逐张取牌。
- 仍保留七格收集槽。大师规则的预设解法可达到六格压力；每局开局保留一条合法可通关路径。任意乱点或洗牌后的状态不保证仍有解。
- 四次取牌内再次消除算连消，每次 100 分递增，五连及以上每次 500 分；按操作步数计，思考时间不破坏连消。使用道具中断连消，不会重复结算或刷分。
- 经典六位挑战码和多人竞速保留旧生成规则。新规则挑战码带 `V2-` 前缀，并能从分享文本恢复。同一种子在两套规则中不被混同。旧成绩不删除，新规则另存成绩。
- 取消旧消除动画任务，避免重开或下一关后旧回调修改新棋盘；补正最后三张尚在消除动画时的胜利成绩计数。

## 验证设计

- 保留全部既有 TileGameTests；新增 240 个新规则种子解法重放、12 个关卡顺序解锁与存档、连消/撤回计分、旧新挑战码复现。
- 不读取预设解法的可见信息贪心策略，对每档 60 个种子实测，记录新轻松/进阶/大师与旧困难通关数。这个数字用于固定样本比较，不冒充真人通关率。
- iOS 原生检查 12 种图案均有可见像素且互不相同；输出首页、440×956 大师棋盘、375×667 进阶棋盘和 956×440 横屏棋盘，检查旧成绩解码。
- UI 自动化实际从首页开局、选择可拿的牌、撤回、确认返回首页；没有注入胜利或跳过碰撞/遮挡规则。
- 独立 `[tile-tests]` 范围执行原生与 UI 回归。修复分支不更新 Release 或上传 TestFlight。

结果待当前源码 CI 完成后填写。
