# 第一批：固定混战诊断与峡谷视觉样板

## 范围与视觉标准
只在设置的固定 3v3 压测入口替换现有 canyon 地图视觉；不改格子、路线、碰撞、射程、伤害或草丛隐身规则。原视觉可切回。深紫低噪声大块地板，粉紫墙箱，暗侧面/亮顶面/倒角/接触底座，低矮定向绿色叶片。原创程序化模型，无截取的游戏贴图。共享材质/叶片网格，墙体合并，不新增动态阴影或粒子。没有收到所述参考图附件，不能确认图中亮绿色区域用途，也不声称精准复刻。

## 对照方法
大厅→设置→显示对局性能→完整效果→固定 3v3 混战。canyon-3v3-v1 固定种子，双方各游侠/骑士/法师，六名机器人按实际规则交战，每1800个60Hz模拟步重复，无奖励。诊断选项互斥，下一局生效：数字、粒子、人物描边、30Hz骨骼采样；时钟和攻击状态继续推进。先完整效果，之后一次仅改一项。压力场景不是玩家手感验收。

复制报告包含版本/提交、设备/系统、全局间隔直方图、最近120次回调、同步CPU阶段、资源创建、活跃数量、热状态。慢回调阈值 >34.333ms，超60Hz预算阈值 >17.667ms。全局P50/95/99为1ms向上分桶，最后1000ms桶含更长停顿。阶段嵌套不可求和；CPU阶段/资源计数自启动启用诊断时累计，帧与活跃峰值每局重置。活跃数量每秒采样可能漏短峰值。模型/音频冷加载需开启后重启。GPU时间、实际呈现FPS和功耗未测。

自动截图 arenaBenchmarkOld / arenaBenchmarkSample 固定同一模拟第900步、同角色/相机/设备；冻结战斗仅用于画面对照，不能作为性能成绩。正常压测不冻结。表现层动画/粒子时间不保证逐像素一致。CI实际打开截图后才能确认画质。

透视相机，偏移(0,16,12.5)，俯角约52.0°；横屏参考平面半宽12世界单位，FOV随宽高比求出，前视4.2；地图1格=1单位，碰撞半径0.42，模型标称缩放0.95。地图尺寸由报告记录，不等同屏幕视野；透视下不同深度可见格子数不同。样板墙1格宽、约0.99高，草尖0.48–0.62高。未凭直播外框估计原作相机。
