## 手机一键入口

大厅设置 → 一键连续性能诊断 / 导出。正常基准与每个关闭项分别运行一轮，保持同地图样式、设备方向及外部环境；每轮约132秒。固定种子170017、峡谷、固定中心镜头，4组各预热3秒+采样30秒：

1. 静止空场：隐藏占位角色和血条，不执行其骨骼采样、AI或输入；地图完整保留。
2. 单人走路：游侠在中央畅通行来回移动，固定脚本，不执行机器人AI。
3. 多人无攻击：6角色执行机器人移动，但拦截攻击/技能/道具输入。
4. 多人混战：相同6角色正常AI战斗；诊断夹具把复活位置放回中央固定点，避免角色复活后长时间离开镜头。伤害与碰撞规则保留，正式对局出生点不变；报告明确记录这项夹具差异。

独立选项：关闭骨骼但保留移动；关闭草丛显示但保留原格子、遮蔽与碰撞规则；关闭人物描边；关闭飘字与粒子；关闭机器人逻辑。前4类视觉开关不修改伤害模拟。关闭AI会同时改变移动与攻击事件，因此只靠帧率差不能把差值全算成AI耗时，须结合分项CPU判断。

导出JSON包含每次回调间隔、控制器/场景CPU、每秒RSS内存和热状态、对局/大厅活跃刷新驱动数、MatchView body求值次数、角色/弹道数量。慢回调阈值>34.333ms，同时报告>18.333ms预算偏离；保留每帧连续记录，不用单张FPS截图。帧记录预留容量且有上限；原始记录使用值类型固定宽度行，导出序列化在采样结束后。内存包括诊断缓存；各组可能共享已加载资源，不冒充冷启动对照。

后台、离场、用户提前结束都会导出未完成标记。导出使用真实系统分享面板，不创建新计时器或刷新驱动。此入口代码和回归需通过本批云端；手机实际运行/导出尚未验证。一次约2分钟测量不代替20–30分钟热稳定性验收。
