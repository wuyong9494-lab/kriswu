## 本轮实现

- `DuelCharacterAnimation` 按规则 tick 选择动作，把出拳接触帧映射到各招式的有效期；命中停顿与暂停冻结动画时钟。抓取、180 tick 锁臂、释放按核心时间线播放，动作不能改写伤害或延长控制。
- 对战进入时只解码一次模型，两个实例分别持有骨骼、材质和姿态缓存。退出时清除实例与资源引用，不设置全局人物缓存。手机贴图限制为 1024，避免对战中读文件。
- 原 glTF 加载器增加显式 PBR 选项；默认行为保持原样。启用后接入法线、粗糙度、金属度以及打击反馈；粗糙度取 G 通道，金属度取 B 通道。
- 全身模型沿用角色朝向与倒地规则。鞋底参考点随脚骨变化，插值时修正穿地；两人完成姿态后做有限次手腕约束。调整真实人物的站位与临时对手的被抓手臂，不修改战斗坐标和命中框。
- 模型缺失或完整性检查失败时显示原动作替身，并在暂停页说明状态。页面不要求玩家手动导入文件。

- Push：核心规则、合成数据加密包校验、设备未签名编译、原替身生命周期、材质回归及 UI 流程。
