## Concrete release path and remaining gates

`App/Info.plist` marks this source version as requiring a private resource pack for promotion. `.github/scripts/arena_private_pack.py` reads exact `id`, `bytes` and `sha256` from the release request. A download URL is supplied only through the `ARENA_PRIVATE_PACK_URL` Actions secret; it is not part of source, release JSON, application code or logs. The script checks the outer digest and every internal payload. XcodeGen explicitly copies the pack as a main-App resource. Archive verification requires the single exact file at `ShiftReminder.app/arena-original-resources.arenapack`, before Apple upload.

Only the private TestFlight promotion job obtains the pack. Public build jobs and the narrow renderer-test workflow do not obtain original assets. Promotion artifact uploads contain identity/status JSON only, not the IPA, app archive, resource pack or private URL. The narrow iOS resource workflow additionally runs synthetic face-renderer tests. The latest completed narrow native execution is resource validation 31 linked above; later player-card/pass checks are separate pending acceptance.

The release request pins the exact source CI, source SHA, build number, raw pack digest and compressed transport digest. Released 554 has no validation-deferral or capture-skip flag.
