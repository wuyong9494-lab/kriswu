# 徐骁个人头部（2026-11-16）

角色名采用用户指定的 **徐骁**，目标套装为嬴政／王朝奠基者。Dropbox 的 `徐.fbx` 实际为 ZIP 容器，已校验并读取其中真实 FBX 和四张原始 PBR 贴图。源文件 SHA256 `661768850d4f64c8bc252200961c052f0643902da394c15c5cd189ad6841b560`，350,235,206 bytes。

输入是静态西装半身像，7,562,286 个三角形，无骨架／动作。已裁切出完整头部和颈部，保留本人的五官、耳部、发型及原始贴图；按源 UV 聚类减面并将贴图缩为 2048。导出的真实 GLB 已重新导入 Blender，并检查正面、四分之三侧面与侧面。没有使用图像代替三维模型。

最终头部为 142,154 个三角形、55,355 个逻辑顶点，GLB 20,354,880 bytes，SHA256 `c2242893775f0ba0fb21e88d830419ff41afa117dd22f0aae2ea577e25d37ee4`。相对全半身像减少约 98.1% 三角形，该比例包括移除衣服和肩部。导出因 UV 接缝有顶点拆分，不把逻辑顶点数当作 GPU 顶点数。未做真机性能认证。

处理分为 `prepare → coarsen → finish` 三个独立 Blender 进程，并保留带 SHA 的中间文件，避免高面数原模型与后续计算同时占用内存。体素重构和统一 QEM 的候选在预览中损坏了脸部，已排除；最终使用保留原表面和 UV 的版本。

**仍待完成：** 真实嬴政套装的身体、装备及动作源身份，头部比例／颈部衔接／骨骼绑定，角色技能、选角入口、联机和整包原生验收。社区表中的 D20／AGL49 是资源检索线索，不冒充已经取得的套装。当前导出是可用于后续装配的个人头部，不能标记为完整嬴政角色，也没有触发 TestFlight。

原始照片纹理、模型和检查图保存在私有检查点。公共提交只包括处理代码、文件身份和验收状态。
