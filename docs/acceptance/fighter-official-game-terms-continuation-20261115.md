## 两次点击的限定条件

沿用官方 APK 19221、固定 SHA-256 和 `armeabi-v7a` 安装要求。观察仍与所有后续读取共享原有 180 秒截止时间，模拟器总存活时间仍受 600 秒限制，不增加第二次启动或点击重试。

第一次操作前重新取得原始 PNG，并核对前后目标包唯一 PID、前台 activity/window 和图片尺寸。只有原始 PNG 的 SHA-256 与已逐张查看的两张 `1920 × 1080` 条款原图之一完全相同，才允许在 `(428,869)` 发出一次 I AGREE 触控。

第二次操作重新取得现场和身份回执。图片中仅允许 `[410,447) × [851,888)` 的 37 × 37 复选框内部发生像素变化，其余 RGBA 像素必须与第一次实际匹配的参考图完全相同；不能切换到另一张参考图。满足此条件才允许在 `(1444,874)` 发出一次 CONTINUE 触控。背景动画、按钮颜色变化、其他文字变化、PID 或前台变化、超时，都会停止该流程，不放宽区域或猜测新位置。

`checkboxVisualDeltaObserved` 仅表示上述局部视觉变化，不能据此声称复选框语义已确认。`checkedStateVerified`、`termsAccepted`、`userConsentConfirmed` 保持 false。输入意图、实际调用和返回、后续页面观察、初始化状态以及资源取得情况分别记录；点击返回成功不能算作初始化完成。意图一经预留就不再重试；若预留后缺少进程回执，实际输入结果为未知，不能由零份确认记录推断“没有点击”。

输入动作使用 `min(原观察截止时间, 本次截图开始时间 + 5 秒)` 这个固定截止时间。先写入意图，再检查现场新鲜度；ADB 包装层的读盘、身份检查以及日志打开不会顺延截止时间，真正创建输入进程之前还会再次检查。

截图、logcat 和动作回执按现有证据封装保存，公共仓库不提交这些原始私有内容。缓存检查只保留既有普通目录和大小上限，不做 root、run-as、权限修改、登录或 URL 猜测。

## 图像读取依赖

受保护工作流在任何 SDK/APK 下载之前，使用独立 Python 3.12 虚拟环境安装一个无额外依赖的固定 Pillow wheel。官方 [PyPI 13.0.0 文件页](https://pypi.org/project/pillow/13.0.0/) 列出的 CPython 3.12 / manylinux x86_64 wheel SHA-256 为 `42d63be3af4f9b951b199b0a9d23365d37ab14687e6d77b74940432c8515c4ca`；安装时强制校验该摘要和实际版本。依赖或 Python 版本不符时，在启动前停止。
