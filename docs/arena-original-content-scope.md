## 接入必须对应真实文件和真实玩法

当前 `arena-asset-configuration.json` 与 `arena-vendor-runtime.json` 是审计和
打包校验清单，App 不通过它们动态注册角色、地图或大厅。实际映射在 Swift
代码中。把文件放进 App 目录或增加清单条目，不等于资源已显示和玩法已生效。

| 内容 | 可以沿用的代码 | 真实版本包还必须提供、或必须实现的内容 |
|---|---|---|
| 大厅 | SwiftUI 导航、现有页面状态、图片加载 | 对应版本的背景、图标、字体、布局、动画及页面状态映射 |
| 英雄 | GLB/glTF 子集加载、骨骼动画和挂点 | 模型、贴图、动作、坐标转换；各英雄技能行为和稳定 ID；存档与联机兼容 |
| 地图 | 格子地图、碰撞、模式池、道具缓存 | 实际布局、环境资源、碰撞/破坏属性、出生与目标点；缺失地形规则 |
| 技能特效 | 事件、弹道与粒子系统 | 纹理或模型、时间线、事件映射；不能用更换外观代替技能实现 |
| 音频 | WAV/M4A 播放、混音、场景切换 | 实际曲目与角色音效、事件映射、循环点和音量 |

现有 `GLTFModel` 不包含 SC/SCW 或完整客户端解码器。本包的 7,739 个 GLB
全部采用 `FLA2 + BIN`；不能只改文件头或把 FlatBuffer 换成 JSON 就视为完成。
本次样本已实际展开网格、骨骼与 RLE 动作到标准 glTF，再嵌入已解码贴图。
标准格式检查通过仍不等于 iOS 端加载、外观、动作或技能验收通过。
服务端模拟器、协议客户端、编译后的客户端和渲染源码工程仍须分别判断。
