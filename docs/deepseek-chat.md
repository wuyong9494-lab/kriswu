# DeepSeek 问答
- 在首页左上角点 DeepSeek，从独立页面发送文字。它和「发数传计划」是两条不同的入口；两者共用设备钥匙串里的 API Key。
- Flash / V4 Pro 与普通 / 深度思考独立选；默认 V4 Pro + 深度思考（max）。普通模式上限 8,192 token，深度模式上限 32,768 token。支持流式回复、停止、新聊天和复制代码块。对话只在本次页面会话保留，不保存历史。
- 问答不读取排班、站名表、群配置或计划图片。只能发送用户主动提交的文字和本轮所需的聊天历史。不执行代码、不自动外发消息。
- iOS 验收：个人和管理者首页入口都可点；未配置 Key 提示到设置，取消不发送；确认文字发送后验证回答、追问、停止、新对话、代码复制。换设备/首次使用仍需单独设置自己的 Key。
- 真实 API 验证使用公开或合成文字，不需要真实班次、账号或计划；不把 Key 添加到 CI 或仓库。
