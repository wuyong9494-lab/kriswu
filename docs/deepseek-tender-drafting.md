# 按招标要求生成投标书草稿

入口：今天 → 左上角 DeepSeek → 标书功能。先把微信或邮件里的文件保存到「文件」，然后在标书页选入一份 PDF/DOCX（最长 16 MiB）。选文件本身不上传。确认后才发送所选文件和用户填写的、已核实且获准外发的投标资料。共用设备上的 DeepSeek Key；不读取值班资料。

模型按招标要求拟写正文、逐条响应和待补项，状态「已起草」不表示满足投标资格或审查通过。正文须审阅具体承诺；材料、证件、价格和签章不能交给模型凭空补齐。引文只在从原文件本机提取到的文字中核对，页码和章节仍需人工确认。扫描版或图表复杂的文件可能无法在本机核对摘录。当前不合并多份补遗，不复刻原 Word 模板的版式或填写原表单。

导出生成独立的可编辑 Word 草稿，含正文、逐项响应表、证据与检查清单，用户从系统分享面板自行选择目的地。原文件不覆盖，不自动发送或提交，不保存聊天记录。联网端请求短期文件有效期并尝试删除上传的源文件；不把 API 删除回执当作服务日志或所有副本的保留保证。

验收：用模拟或已脱敏获准的文件，测试取消（无上传）、拒绝外发、缺 Key、失败后草稿保护、标题/必填项逐条核对、导出后可编辑与可分享。使用合成测试值，CI 中不要配置真实资料或真实 API Key。
