## 导入契约

- 世界 1 单位=1 地图格；脚底原点 y=0，Y 向上。交付模型正面 +Z，导入清单显式记录转换，不修改碰撞半径来迁就造型。本批按实际旧游侠约 1.44 单位的身高对齐，新游侠约 1.51 单位；源模型 2.411 米通过明确的导入缩放归一化，其他资产逐一测量。
- 必需动作：Idle、Run、Attack、Skill、Hit、Death、Victory；游侠有装填机制时增加 Reload。清单逐项映射到 `BrawlerLook`，记录动作时长、发射/伤害关键帧、上下半身混合与循环边界。
- 骨骼命名稳定；手部武器挂点与投射物出口单独提供，不能以整个模型中心发射。移动动画原地循环，位移由模拟控制。
- 当前导入器读取三角网格、基础色、UV0、JOINTS_0/WEIGHTS_0、逆绑定矩阵及 translation/rotation/scale；STEP 和 LINEAR。CUBICSPLINE 被降为线性，必须离线烘焙再验收。不要依赖未实现的 morph、材质扩展或完整 PBR 效果。
- 交付无压缩 glTF 2/GLB；纹理 PNG/JPEG；优先不透明材质。当前默认贴图上限 512，不能假设高分辨率原图会原样显示。战斗/大厅不同预算必须实测后确定，尚无面数/骨骼上限验收数据。
- 接入检查：尺寸/脚底/朝向 → 挂点/纹理 → 全动作 → 隐藏恢复/死亡复活/切换 → 同视角截图 → 冷加载/混战耗时；许可及来源随资产提交。

## 音频样板

原有 WAV 与生成脚本保留。`scripts/arena_theme_sample.py` 为本次原创程序化配乐研究，无第三方录音/采样或原版旋律引用。生成 32 小节 A / A变奏 / B / A回归：大厅 112 BPM、68.57秒；战斗128 BPM、60秒；共享动机的胜/负短句各5秒。并非把旧30秒循环拼接。

交付 `App/ArenaSounds/arena_theme_{lobby,battle,win,lose}.m4a`；设置开关启用，重启生效，关闭可退回原曲。PCM生成检查：无削波、约−20 dBFS RMS、端点差0。AAC编码后的实际循环接缝、响度主观一致性、旋律质量、混音遮蔽与真机播放均未试听验收；数值检查不代表听感通过。

播放逻辑与创作分开验收：独立 off/lobby/battle/result 状态和 background/interruption/renderer 暂停原因；暂停不改变场景。耳机拔出保持暂停，用户明确恢复；遵循 ambient 和外部音频提示。预热播放器，不在命中路径同步创建，普通音效最多8路/含关键反馈最多12路。音乐/音效音量与静音独立持久化，原总静音保留。来电、蓝牙、拔插、其他App音频、实际淡入淡出与循环测试仍需设备验证。
