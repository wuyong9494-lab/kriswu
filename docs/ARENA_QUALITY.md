# 乱斗质量升级

基线：bca1db071182a126bf2766771574a4bb04f53fe8；开发代码在 claude/program-development-n811n8，main 为旧版。

## 第一轮：性能基础

已实现：直接骨骼采样、复用三层动画姿势、头像生成取消、前后台刷新生命周期、可选性能面板。
发布分支：codex/arena-performance-1。工作流等 macOS 构建和 Linux 核心测试成功后上传 TestFlight。

验证限制：云端编译与算法测试不能代替真实手机帧率、GPU、热状态与触控测试。面板采样 CADisplayLink 回调频率，不等同于 GPU 实际完成帧率；逻辑/场景数字仅统计同步 CPU 更新。

## 真机验收

同一手机、同一画质、同一地图和人数，分别测试旧版和新版：
1. 冷启动进入大厅、第一次打开角色选择、立即关闭角色选择。
2. 首次进入对局；持续移动、瞄准、连续攻击；多人集中释放技能。
3. 连续游玩 10 分钟，记录热状态和 P95 帧间隔。
4. 游戏中进入后台再返回，控制中心打开再关闭；退出对局、再来一局。
5. 房主与客户端分别测量；验证没有把网络插值抖动误认为渲染卡顿。

目标：支持设备上以稳定 60 FPS 为目标（16.7 ms 帧预算），先测量再定画质分档，不以降低整体游戏速度掩盖掉帧。用 Instruments/Metal 工具补测 GPU、绘制调用和内存。

## 后续交付顺序

1. 完成加载时间、CPU/GPU 和帧时间实测；再决定解码分离、资源预热、地图分块和可见性更新策略。
2. 选三种战斗定位，制作可复用的武器动作、出手时序、弹道、命中声音与特效标准。
3. 制作一套统一的原创或授权角色资产；通用奇幻素材无法单靠调色达到目标外观。
4. 两张精修地图与一个主玩法形成完整可玩版本；路线、掩体、争夺节奏先于环境装饰。
5. 大厅整体视觉与角色展示统一，再扩充其他模式。
