# 游侠原创角色 v1 接入记录

本批只推进一个游侠角色，不扩充地图、模式或其它角色。旧 `Rogue.glb` 保留；默认游侠明确改用 `Ranger_Original.glb`。

## 已实现

- 原创头脸、发束、奶油色上衣、蓝绿短披风、皮革护腕和靴子、紧凑弩弓；可编辑 Blender 源文件、贴图、22 节点骨架、8 段动作一并交付。
- 新角色单个蒙皮 primitive、单个不透明材质，保留作者法线；不加旧的 4.8 cm 膨胀描边、饱和度放大、呼吸缩放和攻击姿态放大。
- 游戏攻击仍立即发射；新模型从待发姿态进入后坐，发射时将模型对齐实际瞄准方向，枪口反馈取 `muzzle` 节点。弩箭视觉高度随新弩口高度校准；伤害、速度、射程、地面碰撞均未改动。
- 可重复的大厅和战斗新旧资产对照只在 `-demo` 参数下启用，普通游戏入口不提供替换为旧模型的开关。
- 增加 GLB 权重、逆绑定、循环接缝、脚底及跑步接触段检验；增加 iOS 真实导入、8 段动作、蒙皮、枪口方向测试。原有隐藏/重现、连续移动攻击、死亡复活测试继续对游侠执行。

## 本地证据与限制

`python3 scripts/assets/validate_ranger.py` 通过。实际打开了正面、侧面、背面、俯视和动作渲染检查；这些是 Blender 资产预览，不能替代 SceneKit 游戏截图。

静态统计比较的是完整 GLB 文件，旧资产中的隐藏配件和未使用动画也在统计中，不把 primitive 数直接声称为游戏实际 draw call 数。新网格三角形更多，设备 GPU 和长期热状态未测。

当前环境没有 Xcode、连接的 iPhone 或 Instruments。iPhone 17 Pro Max 真机性能、连续游玩 20–30 分钟、音画触觉一致性均**未验证**。新增云端 iOS 编译、动画回归、同机位截图正在等待提交后检查；编译通过不等于视觉通过。
